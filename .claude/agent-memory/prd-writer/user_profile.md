## 역할 및 기술 수준

- NestJS 모노레포 프로젝트를 직접 구현한 시니어 수준의 개발자
- 구현된 기능을 바탕으로 PRD 문서화를 요청하는 패턴 (구현 후 문서화)
- 기술적 세부 사항(Prisma increment, CLS, RBAC 등)에 익숙함

## 작업 방식

- 구현 내용 개요를 제공하면 PRD를 자동으로 완성 형태로 작성 요청
- 기존 구현 문서(docs/implemented/)를 참조하여 정확도를 높이는 것 선호
- 한국어로 모든 문서 작성 요구

## 문서 저장 경로

PRD 문서는 docs/prd/{domain}-prd.md 경로에 저장
